Создание интерактивной презентации в DeepSeek

для любого текста (сказки, рассказа) на 12 предложений с 12 картинками

Общий план работы

  1. Выберите произведение.
  2. Промт №1 → адаптированный текст + 12 вопросов.
  3. Проверьте и откорректируйте.
  4. Промт №2 для создания промтов к картинкам (в том же диалоге).
  5. Создайте папку на компьютере с названием произведения и положите в неё 13 картинок: title.jpg и 1.jpg…12.jpg (картинки генерируете отдельно в Алисе, используя промты из пункта 4).
  6. Промт №3 (в том же диалоге) – попросите ИИ сгенерировать HTML-код, автоматически подставив в него данные из предыдущих ответов (предложения, вопросы, подсказки).
  7. Проверьте код в DeepSeek (кнопка «запустить»), при необходимости правьте.
  8. Сохраните presentation.html в ту же папку с картинками.
  9. Откройте presentation.html в браузере.

Пошаговая инструкция

Шаг 1. Подготовьте исходный текст

Выберите сказку, рассказ или другое повествовательное произведение. Текст должен быть не слишком длинным – позже вы сократите его до 12 простых предложений.

Шаг 2. Адаптация текста и создание вопросов

Откройте чат с DeepSeek и скопируйте этот промт (вместо [Название произведения] вставьте название вашего произведения). Этот и все следующие промты отправляйте в одном диалоге.

Промт №1 (полная версия):
Ты — эксперт по адаптации литературы для детей с РАС и лёгкой умственной отсталостью. Мне нужно адаптировать произведение "[Название произведения]" до 12 простых предложений. Каждое предложение должно: - содержать от 5 до 8 слов; - описывать наиболее важные для сюжета события, наиболее важных персонажей и их ключевые действия; - явно указывать причины поведения героев (в том числе их эмоции); - быть простым по структуре: иметь только одну грамматическую основу. Допускаются не более двух однородных членов одного типа (например, два сказуемых или два подлежащих); - быть максимально простым по пунктуации: избегай прямой речи, причастных и деепричастных оборотов, а также сложных конструкций с несколькими запятыми; предпочтительны предложения без внутренних знаков препинания; - передавать одну чёткую мысль или действие, без лишних пояснений и уточнений внутри предложения; - идти в хронологическом порядке, без временны́х скачков; - давать новый визуальный образ для иллюстрации: каждое предложение должно описывать событие или действие, которое не повторяется в других предложениях. Не используй разные фразы для одного и того же события. Важно для смысловой ясности: - Устаревшие и сложные слова заменяй на простые современные синонимы, доступные для понимания детей. - Если в сюжете есть действие, которое может быть незнакомо детям (например, прядение, ткачество, кузнечное дело), замени его на общее понятие («работать», «делать») или добавь краткое пояснение. - Если в сюжете есть неочевидное, волшебное или нелогичное действие (например, превращение, необычный способ получения помощи), дай в том же предложении краткое пояснение (от 2–3 слов). Если пояснение невозможно без усложнения — упрости или опусти этот элемент, если он не критичен для основной мысли. - Включай в адаптацию только тех персонажей, которые влияют на развитие сюжета и финал. Каждый новый персонаж должен быть представлен с указанием его роли или связи с главным героем (например, «старшая дочь», «проезжий купец»). Не вводи персонажей без пояснения их значимости и не добавляй тех, кто не важен для конечного результата. - Каждое следующее предложение должно логически вытекать из предыдущего. Если происходит важное событие (например, женитьба, награда, спасение), должно быть понятно, что к нему привело (предшествующий поступок героя или появление нового персонажа). - Финальное событие должно вытекать из логики характеров, предшествующих действий и общей морали произведения, а не быть механическим следствием отдельного действия или случайностью. Финальное предложение должно явно связывать финальное событие с личностным качеством или поступком героя. - Эмоции героев должны быть подкреплены действиями или причинами (например, «корова жалела и помогала», а не просто «жалела»). При адаптации используй только общеизвестный сюжет. Если есть разные версии, выбирай самую распространённую и не добавляй своих домыслов. Затем придумай ровно 12 вопросов на понимание текста. Требования к вопросам: 1. Формулировка вопроса — короткая, понятная, без лишних оборотов. 2. Каждый вопрос имеет 4 варианта ответа (А, Б, В, Г), только один правильный. 3. Варианты ответов — конкретные, без абстракций, метафор, двусмысленностей, доступные для детей с РАС. 4. Обязательно включи: - вопрос о главном герое (например, «Как зовут главного героя?» или «О ком эта сказка/рассказ?»); - вопрос о значении малоизвестного термина, если такой есть в тексте (например, «сирота», «купец», «царевич»); - вопросы по содержанию (кто, что, что сделал, где, когда, какой); - 2–3 вопроса на умозаключение (почему, зачем, чем закончилось); - вопрос об основной теме (главной мысли) — ПОСЛЕДНИЙ (№ 12) в форме «Чему учит эта сказка?» (или «рассказ?»). Варианты ответа — обобщённые моральные (например, «доброта помогает», «зло наказывается», «трудолюбие вознаграждается»), но не дублирующие конкретное финальное событие. 5. Вопрос об авторе включи, если автор известен, иначе пропусти. Для каждого вопроса укажи подсказку: - если вопрос об авторе — подсказкой служит полное имя автора (например, «Александр Сергеевич Пушкин»); - если ответ на вопрос прямо и однозначно содержится в одном конкретном предложении текста — укажи номер этого предложения (оно же номер иллюстрации); - во всех остальных случаях (ответ требует обобщения, вывода, или находится в нескольких предложениях) дай текстовую подсказку — короткое пояснение или вопрос, который наводит ученика на правильный ответ, без указания номера предложения. Выдай результат в формате: === АДАПТИРОВАННЫЙ ТЕКСТ === 1. [предложение] ... 12. [предложение] === ВОПРОСЫ === Вопрос 1: [текст] А) ... Б) ... В) ... Г) ... Правильный ответ: [буква] Подсказка: [номер, полное имя автора или текст] ... и так до Вопроса 12.

Шаг 3. Проверьте и скорректируйте

  • Убедитесь, что каждое предложение содержит от 5 до 8 слов и описывает одно действие.
  • Проверьте логику вопросов и правильность ответов.
  • При необходимости просите ИИ исправить (например: «Исправь вопрос №3»).

Шаг 4. Создание промтов для генерации картинок

После получения адаптированного текста и вопросов, не выходя из диалога, отправьте Промт №2. Он попросит вас ввести название произведения (если вы его ещё не указали) и на основе вашего текста создаст подробные промты для генерации иллюстраций.

Промт №2 (полная версия):
Ты — эксперт по созданию промтов для генерации изображений. Задача: пользователь даёт текст, который уже разбит на отдельные предложения (каждое предложение — одна сцена, один слайд). Также пользователь может дать название презентации. Ты должен создать промты для генерации иллюстраций для каждого предложения, а также один дополнительный промт для титульной картинки презентации. Порядок действий: 1. Проверь, передал ли пользователь список предложений. Если нет — попроси вставить текст (предложения должны быть разделены, например, каждый с новой строки или с нумерацией). Не придумывай текст самостоятельно. 2. Попроси пользователя ввести название презентации (если не указано). Если пользователь не дал название, используй первое предложение как название или предложи обобщающее название на основе содержания. 3. Проанализируй содержание: жанр, тон, персонажи, ключевые события, атмосферу. На основе этого анализа предложи подходящий визуальный стиль для всей серии иллюстраций, включая титульную картинку. Опиши стиль кратко, но ёмко: цветовая гамма, характер линий, проработка деталей, манера исполнения. 4. На основе текста определи всех персонажей, которые появляются в сценах. Для каждого персонажа создай единое описание внешности: цвет волос, цвет глаз, рост, особенности (например, хвост у русалки), а также одежду, в которой он появляется (если одежда меняется по сюжету — укажи это, но для каждой сцены в промте нужно описывать ту одежду, которая соответствует сюжету, но она должна быть одинаковой для всех сцен с этим персонажем). Если в тексте не указаны детали, придумай их, исходя из стиля и контекста. 5. Спроси пользователя, устраивает ли его предложенный стиль и описание внешности персонажей. Если пользователь хочет что-то изменить — прими его правки и используй обновлённые данные. 6. После утверждения стиля и внешности создай промты: а) Титульная картинка: создай отдельный промт для обложки презентации. На ней должно быть крупно написано название презентации (в виде текста на картинке, если генератор поддерживает текст, или просто название может быть на баннере, но лучше предложить вариант с текстом, но учитывая ограничения генераторов, можно предложить просто красивую сцену с названием, написанным на отдельном элементе, например, на свитке или на облаке). Также можно добавить имя автора (если пользователь укажет). В описании укажи, что это титульный слайд, он должен отражать общую тему истории, возможно, с изображением главного героя или символа. б) Для каждого предложения создай отдельный промт, как описано ниже. 7. Все промты пиши на русском языке. Каждый промт (и титульный, и для сцен) должен: - начинаться с фразы: «Создай иллюстрацию в стиле: [повторить описание стиля дословно]». - для сцен: обязательно перечислить всех персонажей, присутствующих в данной сцене, с их полным описанием внешности и одежды (это должно повторяться в каждом промте, чтобы внешность персонажей оставалась неизменной от сцены к сцене). - для титульной картинки: описать, что это обложка, с указанием названия (можно в виде текста на картинке, но если генератор не умеет текст, то просто как элемент декора, например, название на ленте или на табличке), и общую атмосферу. - затем — подробное описание конкретной сцены или титульного слайда: композиция (горизонтальная, соотношение сторон 16:9), расположение персонажей, фон, ключевые объекты, эмоции на лицах, цветовые акценты. - заканчиваться фразой: «Формат: 16:9» (без дополнительных параметров, только текстовое указание). 8. Избегай страшных, жестоких или слишком мрачных образов. Конфликтные сцены передавай мягко, без натурализма. 9. Выдай результат в виде пронумерованного списка промтов. Первым должен идти промт для титульной картинки (под номером 0 или с пометкой «Титульная»), затем промты для каждого предложения по порядку. Каждый промт оформи в отдельный блок кода (тройные обратные кавычки с пометкой plaintext), чтобы пользователь мог легко скопировать его по отдельности. После каждого блока оставь пустую строку для читаемости. 10. Не используй никаких специальных синтаксических конструкций (вроде --ar, --v и т.п.) — только словесное описание, чтобы промт подходил для любых генераторов изображений, включая Алису, Гигачат, Midjourney, DALL‑E и другие. Если текст уже введён — сразу приступай к анализу и предложению стиля и внешности, запросив название, если его нет. Если нет текста — сначала запроси его.

После получения промтов скопируйте каждый из них по отдельности и используйте в генераторе изображений (например, Алиса) для создания 13 картинок. Сохраните их с именами title.jpg, 1.jpg … 12.jpg.

Шаг 5. Создайте папку и положите картинки

Создайте на компьютере папку с названием вашего произведения (например, Колобок). Внутри неё разместите 13 картинок в формате JPG:

  • title.jpg – титульная обложка.
  • 1.jpg … 12.jpg – иллюстрации к каждому предложению (номер соответствует номеру предложения).
Важно: имена файлов должны точно совпадать (регистр важен). В эту же папку позже сохраните presentation.html.

Шаг 6. Сгенерируйте HTML-код презентации (Промт №3)

    function shuffleArray(arr) {
        const a = [...arr];
        for (let i = a.length - 1; i > 0; i--) {
            const j = Math.floor(Math.random() * (i + 1));
            [a[i], a[j]] = [a[j], a[i]];
        }
        return a;

    function renderAllSlides() {
        const fragment = document.createDocumentFragment();
        slides.forEach((data, idx) => {
            const el = renderSlide(idx, data);
            fragment.appendChild(el);
        });
        wrapper.appendChild(fragment);
        updateSlide(0);
    }

    function updateSlide(index) {
        const nodes = wrapper.querySelectorAll('.slide');
        nodes.forEach((el, i) => {
            el.classList.toggle('active', i === index);
        });
        currentIndex = index;
        prevBtn.disabled = (index === 0);
        nextBtn.disabled = (index === totalSlides - 1);
    }

    function goPrev() { if (currentIndex > 0) updateSlide(currentIndex - 1); }
    function goNext() { if (currentIndex < totalSlides - 1) updateSlide(currentIndex + 1); }

    prevBtn.addEventListener('click', goPrev);
    nextBtn.addEventListener('click', goNext);
    document.addEventListener('keydown', (e) => {
        if (e.key === 'ArrowLeft') { e.preventDefault(); goPrev(); }
        else if (e.key === 'ArrowRight') { e.preventDefault(); goNext(); }
    });
